Capture these in the project at the following runtime states using the final device profile:

1. `hero_route_choice` — first route fork with district skyline and runner visible.
2. `transit_transition` — train/station chunk with three-lane readability.
3. `rooftop_risk` — elevated route and collectible corridor.
4. `flow_overdrive` — stage 4 Flow, high-speed VFX and HUD.
5. `runner_collection` — character/progression UI with multiple unlocks.
6. `weekly_competition` — leaderboard/ghost UI.
7. `season_event` — event modifier banner and rewards.
8. `personalization` — cosmetic/board/trail inventory.

Final store export must use publisher-owned screenshots and localized legal copy. The runtime contains deterministic seeded states suitable for repeatable capture.
