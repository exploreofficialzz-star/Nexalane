# ICON USAGE

The icon images in this folder are a generated visual starting point for NEXALANE.

Recommended use:
- 1024px master for source/archive;
- 512px for common production references;
- create platform-specific exports from the master at final packaging time.

Do not place the game title as baked text into the icon unless the final branding system explicitly approves it. Keep the icon recognizable at small size.
