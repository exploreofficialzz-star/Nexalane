# ART + ASSET PRODUCTION BIBLE

## Visual target
Premium mobile CGI with realistic surfaces and lighting, stylized character proportions, readable silhouettes and deliberate color hierarchy.

## Icon
The generated icon master is in `assets/icon/`. Use it as visual direction but keep the logo/title separate from the artwork for store flexibility.

### Icon prompt
“Square mobile game icon, premium realistic 3D CGI, original athletic city courier sprinting toward camera, rain-soaked futuristic megacity, three converging route lanes behind the runner, cinematic blue/cyan versus warm orange lighting, glossy wet surfaces, strong silhouette, high contrast at thumbnail scale, no readable text, no brand logos, no similarity to existing commercial game characters.”

## Character prompt template
“Original stylized-realistic mobile-game runner character, full-body, believable anatomy, distinctive silhouette, athletic street-courier clothing, original accessories, high-quality PBR materials, cinematic rim light, neutral studio background, front/side/three-quarter turntable, clean topology reference, no branded logos.”

## Environment prompt template
“Premium mobile-game 3D environment concept for a fictional near-future megacity, stylized realism, physically plausible architecture, dense but readable street furniture, realistic wet or dry materials, cinematic lighting, strong path readability, no real-world brand logos, original signage language.”

## Obstacle prompt template
“Original mobile endless-runner obstacle, industrial urban design, readable collision silhouette, realistic material response, high-contrast accent markings, optimized low/mid/high detail variants, three-quarter view on neutral background.”

## Performance asset rules
- use atlases;
- compress textures;
- define mip behavior;
- avoid unnecessary transparency;
- create LODs for large props;
- share materials aggressively;
- prefer instancing for repeated geometry.

## Deliverable naming
`category_assetname_variant_lod.ext`

Example:
`env_transitcore_platform_a_lod1.glb`

## Asset acceptance
Every asset must include:
- source/reference prompt;
- license/source record if externally sourced;
- optimized export;
- mobile quality tier;
- collision/interaction notes;
- placement rules.
