# AUDIO BIBLE

## Audio identity
Modern cinematic electronic rhythm with tactile urban foley. Music supports speed and anticipation without becoming exhausting.

## Music package
Create a system of stemmed loops:
- main menu;
- story hub;
- each of 8 districts;
- chase state;
- Overdrive state;
- event state;
- victory/reward;
- store.

Each gameplay track should have:
- base loop;
- intensity layer;
- chase layer;
- Overdrive layer;
- sting/exits.

## Audio prompts
### Movement SFX prompt
“High-quality tactile mobile game foley, athletic runner movement on wet urban surfaces, crisp transients, realistic cloth and shoe contact, short tail, no music.”

### UI prompt
“Premium mobile game UI sound, concise modern electronic click/chime, polished and readable on phone speakers, no melody.”

### Overdrive prompt
“Cinematic electronic acceleration sting, rising tension, wide stereo image, controlled low-end, premium sci-fi urban runner feel, no copyrighted melody.”

## Dynamic mix
When player enters Overdrive:
- duck ambient;
- brighten movement SFX;
- add music layer;
- add subtle low-frequency pulse;
- restore mix smoothly on exit.

## Technical
Use compressed formats appropriate for mobile. Stream longer music assets. Keep SFX in memory only where latency needs it.
